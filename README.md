## What This Project Does

CS:GO Major Draft Simulator provides a front-end workspace for drafting teams and assembling lineups around Major-style scenarios. Build rosters, progress through randomized card draws, and compare different team configurations directly in the browser.

The utility runs as a self-contained, single-file web page, so it can be opened locally, transferred easily, or deployed through static hosting. Its client-side data covers regions and eras, while selection and role placement controls support quick lineup experimentation without a backend.
